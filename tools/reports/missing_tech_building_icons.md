# Technologies et bâtiments sans fichier d’icône correspondant

Comparaison des définitions actives du mod avec les fichiers DDS du mod et de l’installation locale d’Europa Universalis V (jeu de base et DLC). Le nom recherché est la valeur de `icon` lorsqu’elle existe, sinon l’identifiant de la définition. Les icônes de remplacement génériques du jeu ne sont pas considérées comme une icône propre à l’élément.

## Technologies (0 sur 186)

Toutes les avances définies dans le mod disposent maintenant d’un fichier d’icône correspondant dans le mod ou dans le jeu installé.

## Bâtiments (0 sur 152)

Tous les bâtiments définis dans le mod disposent maintenant d’un fichier d’icône correspondant dans le mod ou le jeu installé. Voir `tools/reports/building_icon_installation.md` pour les 102 fichiers ajoutés.

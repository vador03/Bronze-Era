# Icônes de bâtiments installées

- Bâtiments auparavant sans icône : **102**
- Illustrations d’avances réutilisées et réencodées : **45**
- Illustrations générées pour un bâtiment précis : **57**
- Dossier : `main_menu/gfx/interface/icons/buildings/`
- Format vérifié : DDS DXT5, 125 × 125 px, 7 mipmaps, canal alpha réel
- Références de jeu : nom implicite identique à l’identifiant du bâtiment ; aucune définition de bâtiment modifiée

## Méthode

Les 45 réutilisations conservent le sujet des icônes d’avances existantes, mais sont redimensionnées et réencodées selon la convention des bâtiments. Les 57 autres images ont été créées avec l’outil intégré de génération d’images : bâtiment ou monument historique centré, illustration peinte, couleurs sobres, fond alpha transparent, sans texte ni cadre. Les monuments nommés ont chacun un sujet architectural indiqué dans `tools/reports/building_icon_plan.json`.
